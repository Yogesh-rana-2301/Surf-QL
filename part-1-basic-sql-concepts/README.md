# Part 1: Basic SQL Concepts

This folder is a complete beginner-to-interview-ready module for SQL basics.
It covers the exact topics you listed, with notes + runnable SQL + practice.

## What You Will Learn

1. Creating Database
2. Creating Tables and Adding Data
3. SELECT Clause
4. FROM Clause
5. WHERE Clause
6. INSERT INTO
7. DELETE Statement
8. Operators (AND, OR, NOT, etc.)
9. DROP and TRUNCATE

## Suggested Study Order

1. Read lesson files in numeric order (`01-...` to `09-...`).
2. Run `sql/01_schema_and_seed.sql`.
3. Run and modify queries in `sql/02_basic_queries.sql`.
4. Solve `practice/part1-practice-set.md`.
5. Use `sql/03_cleanup_examples.sql` only when practicing cleanup commands.

## Dialect Notes

- Examples are written in MySQL-friendly SQL.
- Most commands also work in PostgreSQL and SQL Server with minor syntax changes.
- `TRUNCATE` and `DELETE` behavior can differ slightly by database.
