# Summary: SQL Operators

## Core idea

SQL operators are used to calculate values, compare data, and combine conditions.

## Types covered

- Arithmetic: `+`, `-`, `*`, `/`, `%`
- Comparison: `=`, `>`, `<`, `>=`, `<=`, `<>`
- Logical: `AND`, `OR`, `NOT`
- Bitwise: `&`, `|`, `^`, `~`
- Special: `BETWEEN`, `IN`, `LIKE`, `IS NULL`, `EXISTS`

## Practical use

- Compute derived columns in `SELECT`.
- Filter rows in `WHERE`.
- Update values in `UPDATE` expressions.
- Apply permission-flag logic with bitwise operations.

## Key points

- Operator choice directly affects result correctness.
- Logical operators are essential for multi-condition filtering.
- Special operators simplify common query patterns.
